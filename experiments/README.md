# Experiments

A collection of programming experiments, technical explorations, and small exercises created to investigate concepts, test ideas, and strengthen my understanding of software development.

This directory serves as a general-purpose workspace for exploring programming concepts without necessarily building a complete application or game.

## Purpose

The primary purpose of this category is **learning through exploration and testing**.

Experiments may focus on individual programming concepts, algorithms, language features, debugging techniques, or unfamiliar technologies.

Some objectives include:

- Exploring programming concepts and language features.
- Testing algorithms and different problem-solving approaches.
- Experimenting with mathematical and logical operations.
- Investigating unexpected behaviour and debugging issues.
- Understanding how specific functions, methods, and tools work.
- Testing unfamiliar technologies and development techniques.
- Practising small programming exercises.

## Experiment Types

Experiments in this directory may include:

- **Programming Concepts:** Small exercises exploring variables, functions, loops, conditions, data structures, and other programming fundamentals.
- **Algorithms & Logic:** Experiments involving calculations, sorting, searching, and problem-solving techniques.
- **Mathematical Experiments:** Exploring mathematical operations, statistical calculations, and numerical processing.
- **Debugging & Testing:** Isolated projects used to investigate bugs, test behaviour, and understand potential solutions.
- **Technical Exploration:** Small experiments involving unfamiliar tools, technologies, libraries, or programming features.

## Development Approach

Experiments are generally kept small and focused on a particular concept or objective.

The emphasis is on understanding how something works, testing different approaches, and learning from the results rather than producing polished or production-ready software.

Experiments may be temporary, incomplete, repetitive, or abandoned once their learning objective has been achieved.

## Organisation

Experiments are organised into separate directories where appropriate.

Related experiments may be grouped together under a common category, while smaller or independent experiments can exist in their own directories.

Each experiment should remain focused on its specific objective without requiring unnecessary project structure or documentation.

## Technologies

Technologies and tools will vary depending on the subject being explored.

Examples may include:

- HTML & CSS
- SQL
- Git & GitHub
- Other programming languages, libraries, frameworks, and development tools.
