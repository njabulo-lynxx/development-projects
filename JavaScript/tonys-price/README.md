# Tony's Price

A small browser-based guessing game built with HTML, CSS, and JavaScript.

## About the Project

Tony's Price is a mini-game inspired by an original fictional world featuring Lynxx, Terrah, and Tony.

Lynxx and Terrah encounter Tony, a travelling medieval merchant with a mysterious collection of merchandise. Unfortunately, the two protagonists are broke. Tony offers them a challenge: correctly guess the exact price of an item to earn it for free.

What begins as a simple guessing game becomes a competition between the two players, with Tony deciding who gets the final opportunity.

## Gameplay

The objective is to guess the randomly generated price of an item, which falls between 1 and 100.

Each round consists of seven attempts:

- **Attempts 1–3:** Lynxx makes his guesses.
- **Attempts 4–6:** Terrah takes her turn.
- **Attempt 7:** Tony awards the final attempt to whichever player performed worse.

If both players perform equally, Tony makes a random decision, accompanied by his own commentary.

After every guess, the game provides feedback indicating whether the actual price is higher or lower.

### Winning and Losing

- **Victory:** Guess the exact price and earn the item.
- **Defeat:** Fail to discover the correct price and receive an opportunity to try again.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

No external frameworks or libraries are required.

## Planned Features

The project will gradually expand beyond its initial guessing mechanic.

Potential additions include:

- A collection of 100 unique items, each with its own description and price.
- An inventory system for keeping track of acquired items.
- Additional item-related interactions.
- More gameplay possibilities involving item acquisition and loss.
- Improved visual presentation and user interaction.

## Project Goals

This project serves two purposes:

1. **Learning:** Practising JavaScript fundamentals, HTML structure, CSS styling, and the relationship between these technologies through practical game development.
2. **Creativity:** Experimenting with game mechanics and introducing elements from an original fictional world into an interactive experience.

The project will be developed incrementally, prioritising understanding and experimentation over rushing towards a finished product.
