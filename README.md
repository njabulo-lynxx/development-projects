# Development Projects

A personal repository for experimenting, learning, and developing my programming skills.

This repository is where I build small projects, test ideas, practise new concepts, and generally figure things out through hands-on development.

## Purpose

The main purpose of this repository is **learning**.

Projects in here do not necessarily need to be polished, complete, or production-ready. Some may be experiments that exist simply because I wanted to understand how something works.

The repository gives me a place to:

* Experiment with programming concepts
* Learn new technologies and tools
* Practise concepts I already know
* Test ideas before turning them into larger projects
* Build small proof-of-concept projects
* Make mistakes and learn from them
* Keep track of my development progress

## Project Structure

Projects are generally kept separate within this repository.

Some projects may have their own folders and documentation, while smaller experiments may simply contain the files needed for the experiment.

The structure may change over time as my projects and learning needs change.

## Project Quality

Not everything here is intended to be professional.

Code may be:

* Experimental
* Incomplete
* Unpolished
* Inefficient
* Poorly structured
* Heavily commented while I am learning
* Completely abandoned

And that's okay.

This repository represents the **learning process**, not the finished product.

## From Experiment to Project

Sometimes an experiment grows into something worth developing further.

When a project becomes sufficiently interesting or useful, I may move it into its own repository and give it:

* A dedicated README
* A proper project structure
* Cleaner and more maintainable code
* A defined purpose
* Additional features
* Proper documentation

The development-projects repository therefore acts as a starting point for ideas that may eventually become standalone projects.

## Technologies

The technologies used in this repository will vary depending on what I am learning or experimenting with.

Examples may include:

* HTML
* CSS
* JavaScript
* PHP
* Java
* SQL
* Git & GitHub
* Other programming languages, frameworks, libraries, and tools

## Learning Philosophy

> Build it. Break it. Understand why it broke. Fix it. Build something better.

I use this repository to learn through experimentation rather than trying to make every project perfect from the beginning.

Some experiments will be useful.

Some will be terrible.

Some will probably make future me question the decisions of past me.

All of them are part of the learning process.

**Active learning repository**

This repository will continue to evolve as I learn new programming concepts, technologies, and development practices.
